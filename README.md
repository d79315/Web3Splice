# Web3Splice

Web3Splice is a decentralized platform for real-time data processing via blockchain-secured gateway nodes, enabling auto-scaling and load balancing.

Web3Splice is built to be simple and practical, focusing on doing one thing well.

**Why Web3Splice?**

- Web3Splice is a decentralized platform
- for real-time data processing via
- blockchain-secured gateway nodes, enabling auto-scaling

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Splice.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure Web3Splice, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
